> **"Apex Update is great. Apex Advanced is Apex Update with more knobs."**

Sibling to [**InfoLCD - Apex Update**](https://github.com/gitpush-mod/se-infolcd-apex-update), tuned for players who want more information density and expanded readouts on their Apex LCD blocks. Same design constraints (client-side only, zero world impact), more scripts and layout options.

</p>

## ✨ What's different vs. Apex Update

| | Apex Update | Apex Advanced |
|---|---|---|
| Core readouts (cargo/power/jump/ammo) | ✅ | ✅ |
| Airlock monitor | ✅ | ✅ |
| Expanded per-subsystem breakdowns | — | ✅ |
| Additional layout scripts | — | ✅ |
| Runs alongside the other | — | Same LCD, one script — pick one per screen |

Both mods target the same Apex LCD blocks. Install both if you want the option to pick per-screen.

## 🚀 Install

1. [Subscribe on the Workshop page](https://steamcommunity.com/sharedfiles/filedetails/?id=3616712902)
2. Enable the mod when creating or loading a world
3. Place an Apex LCD block → terminal → select an `InfoLCD - <thing>` script

Client-side only. Add or remove freely on existing saves.

## 🎯 Compatibility

- ✅ **Space Engineers 1** — actively maintained
- ✅ **Multiplayer + dedicated servers** — client-side, does nothing server-side
- ✅ **Existing saves** — safe to add/remove
- ✅ **Runs alongside Apex Update** — pick one script per LCD block
- ⚠️ **Non-Apex LCD blocks** — not supported by design
